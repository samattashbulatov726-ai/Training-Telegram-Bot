# Анализ погоды в Уфе (2026)

Анализ погодных данных Уфы за период с 1 января по 4 ноября 2026 года (308 дней). Данные получены через API Open-Meteo, визуализация — `matplotlib` + `seaborn`.

## Структура проекта

```text
├── data/
│   └── raw/
│       └── ufa_2026.csv      # Исходные данные погоды
├── analytics/
│   └── figures/              # Папка для сохранения графиков
├── analyze.py                # Скрипт анализа и визуализации
└── README.md
```

## Как запустить

1. Установите зависимости:
```bash
pip install pandas numpy matplotlib seaborn
```

2. Запустите анализ:
```bash
python analyze.py
```

Скрипт автоматически создаст папку `analytics/figures`, сохранит туда 6 графиков и выведет сводную статистику в консоль.

## Данные

| Колонка | Описание |
|---|---|
| `date` | Дата |
| `temperature_2m_max/min` | Фактическая макс/мин температура, °C |
| `apparent_temperature_max/min` | Ощущаемая макс/мин температура, °C |
| `precipitation_sum` | Сумма осадков за сутки, мм |
| `wind_speed_10m_max` | Максимальная скорость ветра, км/ч |
| `weather_code` | Код погодного состояния WMO |

## Что анализируется

- **Температура**: фактическая и ощущаемая (максимум/минимум).
- **Осадки**: распределение количества осадков по дням.
- **Ветер**: корреляция скорости ветра и температуры.
- **Погодные условия**: классификация по кодам WMO (ясно, облачно, морось, дождь, снег, туман, гроза).

## Генерируемые графики

1. `01_temperature.png` — Динамика температур за год.
2. `02_temp_diff.png` — Разница между фактической и ощущаемой температурой.
3. `03_boxplot_temp.png` — Распределение температур по месяцам (янв–окт).
4. `04_heatmap.png` — Тепловая карта температур по дням и месяцам (янв–окт).
5. `05_precip.png` — Гистограмма осадков.
6. `06_wind_scatter.png` — Зависимость температуры от скорости ветра с разбивкой по типу погоды.

Boxplot и heatmap строятся только по полным месяцам (январь–октябрь), чтобы неполный ноябрь не искажал картину.

## Ключевые метрики

В конце выполнения скрипт выводит:
- Количество проанализированных дней.
- Среднюю и максимальную разницу между фактической и ощущаемой температурой.
- Процент дней с осадками и холодных дней (макс температура < 5°C).
- Корреляцию между ветром и температурой.
- Самое частое погодное состояние.
