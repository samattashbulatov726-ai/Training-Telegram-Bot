Анализ погоды в Уфе (2026)
Проект содержит скрипт для анализа исторических погодных данных города Уфа за 2026 год. Данные получены через API Open-Meteo и визуализированы с помощью библиотек matplotlib и seaborn.
Структура проекта
├── data/
│   └── raw/
│       └── ufa_2026.csv      # Исходные данные погоды
├── analytics/
│   └── figures/              # Папка для сохранения графиков
├── analyze.py                # Скрипт анализа и визуализации
└── README.md

Как запустить
Установите зависимости:
pip install pandas numpy matplotlib seaborn
Запустите анализ:
python analyze.py

Что анализируется
Температура: фактическая и ощущаемая (максимум/минимум).
Осадки: распределение количества осадков по дням.
Ветер: корреляция скорости ветра и температуры.
Погодные условия: классификация по кодам WMO (ясно, облачно, дождь, снег и т.д.).

Ключевые метрики
В конце выполнения скрипт выводит:
Количество проанализированных дней.
Среднюю разницу между фактической и ощущаемой температурой.
Процент дней с осадками и холодных дней (температура < 5°C).
Корреляцию между ветром и температурой.
Самое частое погодное состояние.
